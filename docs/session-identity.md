# Session identity boundary

Whale Soul binds a live Session to one individual through a host reservation and a memory-root mirror. The authority stores only identifiers, structural metadata and hashes. Ordinary memory exports do not grant Session ownership.

A first claim requires a genuinely fresh Session and independent observation of its complete event prefix. The observer subscribes at the host root so it also sees the permission initialization that the Web host publishes before persona scope binding. It records an owned first material event only after the actual Agent belongs to this persona scope.

The three official initialization events `permission/preset`, `sandbox/mode` and `approval/policy` are configuration metadata. Their payloads must have the expected fields and values; extra content and unknown events remain material history. This classification does not alter permission policy or authorize any action. A cold resume or fabricated empty projection cannot become a fresh Session.

The observer is disposed with its persona owner. Confirmed Session restrictions remain enforced by the separate host dispatch registry, including after persona unload. A newly selected individual cannot take over an existing Session by changing a prompt or clearing memory.
