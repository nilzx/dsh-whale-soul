# 0.2.1记忆自动修复

[English](release-0.2.1.md)

状态：准备中，尚未发布；npm最新版本仍为0.2.0。

一轮Electron合成记忆损坏测试已通过：首次认证失败后，自动重试完成修复。原文及记录、修订、身份引用保留，当前格式校验通过。更广泛损坏情形和长期表现仍单独验收。

记忆数据问题由独立修复Agent处理，既覆盖升级，也覆盖已有数据损坏。修复目标始终是当前版本的数据规范，不需要为以后每次破坏性变更另外设计迁移流程。

- 健康记忆正常加载；启动或记忆操作发现数据错误时，程序保全来源，再使用当前配置的模型启动修复任务。
- 修复Agent只能查看记忆文件及备份、读取当前数据规范、提交规范化快照并根据校验结果继续修复，不能修改插件文件或执行shell命令。
- 索引、校验元数据和引用由程序生成；可恢复的事实、修订、来源、身份、人格成长、成熟度及清除状态均应保留。
- 结果不合规范会交回Agent继续修；模型或网络临时失败、当轮未完成会自动续跑，不要求用户编辑文件或执行迁移命令。
- 只有通过验证的结果才替换活跃目录。原库保留为回退备份，成功后清理本次临时文件及旧活跃布局；任务重启不会再生成一份备份。
- 确实无法恢复的原始片段单独保全，不凭空补写事实。修复报告、重试状态、诊断不进入记忆正文。

普通V1数据仍可走无需模型调用的本地快捷转换；其他旧布局和损坏数据走同一个当前规范修复入口。[本地管理工具](management.zh-CN.md)作为所有者的可选能力保留，不再是普通升级的必要步骤。
