# 0.3.0 会话记忆提取

[English](release-0.3.0.md)

0.3.0新增`/whale-remember-session`，可从指定DSH会话中提取值得保留的内容。

在鲸鱼娘会话中提供会话ID或DSH会话引用；指定主题时只提取相关内容，不指定时由Agent筛选长期事实、偏好、计划和重要经历。默认自动选择简短概要或必要细节，也可以明确要求其中一种。示例见[会话记忆说明](session-memory.zh-CN.md)。

事实以用户自己的陈述为依据，详细记忆使用所选用户原文，不把尚未确认的助手建议当成已采用步骤。相关片段会归并，并联合比较已有记录以避免重复提取；姓名和惯用称呼会优先进入当前用户的轻量记忆上下文。来源编号、执行回执留在记忆正文之外，导入不增加人格成熟度，也不改人格核心。

在DSH插件页面更新，按提示重启，再新建鲸鱼娘会话即可。从0.2.x更新时，记忆格式、默认位置和已有记录保持不变，无需手动转换或清空文件。原有[自动修复流程](release-0.2.1.zh-CN.md)继续处理旧布局和损坏数据。

本次使用固定的14轮Web会话验证了限定提取、自主选择、重复提取零新增和新会话回忆。提取沿用当前配置的模型，较长会话可能需要多次模型调用。
