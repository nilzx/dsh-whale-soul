# 0.2.3 Windows记忆写入修复

[English](release-0.2.3.md)

版本：`0.2.3`。

此补丁修复部分Windows环境拒绝同步目录句柄、返回`EPERM`或`EACCES`时的记忆写入问题。在0.2.2中，该问题可能阻止记忆迁移或修复启动，使新的鲸鱼娘会话一直等待。

记忆写入现在允许跳过上述不受支持的目录同步。文件内容仍会在发布前同步，文件同步本身失败时仍正常报错。锁所有者文件写入失败后，会清理本次候选目录。感谢[@zhoupure183](https://github.com/zhoupure183)贡献[PR #1](https://github.com/nilzx/dsh-whale-soul/pull/1)。

在DSH中更新插件，按提示重启，再新建鲸鱼娘会话即可。已有记忆继续保留，自动迁移和修复按需续跑；本修复无需手动编辑记忆。

CI现已在Linux和Windows上运行Node.js 22、24的现有测试及打包检查。本地另有定向检查注入目录、文件同步失败，并在拒绝目录同步的情况下执行V1迁移和记忆修复。
