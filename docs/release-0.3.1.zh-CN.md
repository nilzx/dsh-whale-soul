# 0.3.1 跨平台人格启动修复

[English](release-0.3.1.md)

0.3.1修复鲸鱼娘在Windows和Linux上的启动失败。0.3.0在初始化人格时强制启用仅实现了macOS版本的隔离层，导致其他平台拒绝加载预设。

现在三个平台统一使用DSH官方的文件、进程和沙箱服务。文件与命令访问遵循宿主配置的权限。命令沙箱运行器不可用时，DSH在执行命令时报告错误，人格与记忆仍可正常初始化。

在DSH的Plugins页面更新插件，按提示重启，然后新建鲸鱼娘会话。升级会继续使用现有记忆，会话记忆提取、人格成长和结构化记忆写入功能继续可用。

Windows、Linux、macOS分别搭配Node 22和24，共六组CI均通过21项测试，包括官方DSH服务下的实际人格初始化、记忆保存与回忆、普通文件访问、只读模式拒绝写入和命令交由宿主沙箱处理。本机Web预设与图片检查也已通过。
