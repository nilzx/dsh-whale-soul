# 0.3.2 适配 DSH 0.2.2 的运行时上下文

[English](release-0.3.2.md)

0.3.2恢复鲸鱼娘在DSH `0.2.2-rc.2`上的可用性。升级到该版本后，鲸鱼娘的请求在到达模型前就报`INJECTED_SURFACE_UNVERIFIED`，新旧会话都无法继续。

DSH 0.2.2把运行时上下文快照写成一段由宿主自有引导语开头的`<system-reminder>`块。插件此前用`joinContextSections()`的渲染结果作为这段文本的身份依据；0.2.2保留该helper另有用途，而Agent循环实际写入的是另一种字符串，因此每个主请求都过不了快照核验。

现在核验同时绑定提醒包装与逐字段落文本；旧的纯文本渲染仍然有效，升级前建立的会话仍保有撤回权限；从活动surface移除过期记忆时写回当前包装格式。文本与段落不一致的内容依旧拒绝而不改写。无需重写会话：失败过的请求没有留下写入，升级后重试可继续同一段对话。

兼容性声明覆盖DSH `0.2.1-rc.3`与`0.2.2-rc.2`。验证：新增的宿主回归测试在未改动的代码上能复现已安装`0.2.2-rc.2`的`INJECTED_SURFACE_UNVERIFIED`，改动后通过；本机测试26项通过，两项宿主测试仅在设置`DSH_RUNTIME_MODULES`时运行；macOS上宿主测试用真实Session与Agent Loop加确定性adapter跑通，并确认清理保留了第三方段落。
