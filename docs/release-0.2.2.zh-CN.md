# 0.2.2软链接记忆目录修复

[English](release-0.2.2.md)

版本：`0.2.2`。

此补丁修复0.2.1在记忆根使用目录软链接时的启动卡住问题。旧记忆可能反复进入修复，而对话一直等待记忆就绪。

插件现在会先解析实际目标目录，再进行迁移或修复。配置的软链接继续保留，迁移、修复暂存、锁和备份使用实际目标目录。同一宿主进程中，指向同一目录的不同根路径共用一个修复任务。

在DSH中更新插件，按提示重启，再新建鲸鱼娘会话即可。已经指向有效记忆目录的软链接可以继续使用。普通V1记忆自动转换，其他已检测的数据错误沿用[当前规范修复Agent](release-0.2.1.zh-CN.md)；本修复无需手动编辑记忆。

验证覆盖软链接V1转换、软链接损坏库修复、最低Node.js 22.12和DSH rc.3集成。实际Electron桌面验收中，原软链接保留，14份源文件与回退备份一致，已有记忆的摘要和详情未变，新会话正常完成回复。这些检查验证本次根目录软链接修复，不表示任意损坏都能无损恢复。
