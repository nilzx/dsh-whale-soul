# 从指定会话提取记忆

[English](session-memory.md)

开发中预览：已发布的0.2.3包尚未包含此Skill，目前仍在检查发布条件。

在鲸鱼娘会话中输入`/whale-remember-session`，用DSH会话引用或会话ID指定来源。说“当前会话”即可处理正在进行的会话。

例如：

```text
/whale-remember-session 从会话<会话ID>中，只记照片备份的流程和约束。
/whale-remember-session 整理会话<会话ID>，自行挑选以后值得记住的内容。
/whale-remember-session 把当前会话中值得保留的内容记成概要。
```

指定主题时只提取相关内容；没有指定时，Agent会筛选长期事实与偏好、持续计划、重要经历和可复用结论。普通命令、寒暄和执行日志通常跳过。没有值得记忆的内容时，可以不新增任何记忆。

默认自动判断详略：简单偏好和宽泛结论保留概要；流程、决策理由、重要经历等按需要保留所选用户原文与关键限定。也可以明确要求“只记概要”或“详细记住”。摘要层保持简短，需要细节时再通过正常回忆读取。

工具通过DSH会话服务读取会话，以用户自己的陈述作为事实依据，不导入系统指令、工具日志或思维内容。助手单独提出的建议、常识补全不会自动变成额外步骤或决定；泛称采用某套流程，也不会补入用户没有表达或具体确认的细节。长会话按小段处理，程序根据原文编号取得来源，不让模型复抄摘录；保存前归并相关片段，并联合比较已有多条记忆，避免把已有内容重新组合后再次保存。导入不会覆盖已有记录。

实际来源会话、消息和时间保存在现有V2证据元数据中。详细正文直接由所选用户原文组成，其中的第一人称属于来源用户。记忆正文只包含实际内容，不夹杂聊天包装、提取报告或操作回执。姓名和惯用称呼作为身份信息保留，并优先装入当前用户的轻量记忆上下文。导入不改变人格补完和成熟度。

当前预览已使用固定的14轮Web会话检查限定提取、自主选择、重复提取和新会话回忆；仍是开发中功能，已发布的0.2.3包尚未包含此Skill。

当前工作区内的会话可以按ID选择。选择其他工作区的会话时，请在请求中带上准确的ID或DSH会话引用；目标有歧义时应先澄清。宿主需提供`sessionQuery`和`skills`服务。历史记录不可读或模型失败时会如实反馈，不声称已经记住。

最终会说明实际保存、已保存和失败的内容。提取使用当前配置的模型，长会话可能需要多次模型调用；无需手动复制聊天记录或编辑记忆文件。
