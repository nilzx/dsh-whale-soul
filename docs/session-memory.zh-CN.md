# 从指定会话提取记忆

[English](session-memory.md)

开发中功能：当前源码预览已包含此Skill，将随0.2.3之后的版本提供。

在鲸鱼娘会话中输入`/whale-remember-session`，用DSH会话引用或会话ID指定来源。说“当前会话”即可处理正在进行的会话。

例如：

```text
/whale-remember-session 从会话<会话ID>中，只记照片备份的流程和约束。
/whale-remember-session 整理会话<会话ID>，自行挑选以后值得记住的内容。
/whale-remember-session 把当前会话中值得保留的内容记成概要。
```

指定主题时只提取相关内容；没有指定时，Agent会筛选长期事实与偏好、持续计划、重要经历和可复用结论。普通命令、寒暄和执行日志通常跳过。没有值得记忆的内容时，可以不新增任何记忆。

默认自动判断详略：简单偏好和宽泛结论保留概要；流程、决策理由、重要经历等按需要保留细节和关键限定。也可以明确要求“只记概要”或“详细记住”。摘要层保持简短，需要细节时再通过正常回忆读取。

工具通过DSH会话服务读取用户和助手的文字，不导入系统指令、工具日志或思维内容。长会话分段处理，最后筛选重复或已被更正的候选。现有记忆会作为避免重复及过时事实的背景；导入不会覆盖已有记忆。

实际来源会话、消息和时间保存在现有V2证据元数据中，助手结论与用户陈述保持不同归属。记忆正文只包含实际内容，不夹杂聊天包装、提取报告或操作回执。重复执行相同提取可复用已匹配的记忆；导入不改变人格补完和成熟度。

当前工作区内的会话可以按ID选择。选择其他工作区的会话时，请在请求中带上准确的ID或DSH会话引用；目标有歧义时应先澄清。宿主需提供`sessionQuery`和`skills`服务。历史记录不可读或模型失败时会如实反馈，不声称已经记住。

最终会说明实际保存、已保存和失败的内容。提取使用当前配置的模型，长会话可能需要多次模型调用；无需手动复制聊天记录或编辑记忆文件。
