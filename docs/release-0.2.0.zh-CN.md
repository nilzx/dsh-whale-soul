# 0.2.0更新与升级说明

[English](release-0.2.0.md)

版本：`0.2.0`。

0.2.0对人格连续性与记忆存储做了较大改造。鲸鱼娘模式继续保留，可更换的人格核心、有经历依据的人格成长、稳固的长期记忆分别管理。

## 主要变化

- 人格与记忆在同一包内分为两个模块。每个个体有独立身份、成长与成熟度，可通过完整导出/导入在不同目录或机器间接续。
- 人格稳定性支持多变、普通、顽固、自动四档；默认自动档随有效经历逐渐稳固。普通聊天不能直接重写人格核心。
- V2记忆支持同一消息多项事实、有来源和历史的纠错、明确不记及更深层召回。回忆问句不能把已知事实改成没有具体值的话题名。更正前先匹配既有事实，目标不明确时询问澄清；更新操作句不进入记忆正文，召回时区分用户经历与Agent经历。
- 明确约定区分提议与双方接受。真实待办状态更新可以核验绑定待办的状态交付约定，但不代表待办背后的工作产物已完成。
- 本地管理CLI支持预览、迁移、导出/导入与精确清除。记忆正文与来源、操作元数据分开保存。
- `/whale-context`显示核心、人格补完、记忆、运行提示和工具的上下文估算占比。本地执行，不调用模型，也不把结果写入记忆。
- 核心升级可重审并接续兼容的既有成长，不重置身份或成熟度。正常技术任务仍会提供所需代码、命令和文件链接。

## 从0.1.x升级

1. 停止旧插件的写入与维护，保全完整的旧记忆根和配置副本。
2. 使用**独立的目标根目录**，按[V1迁移流程](management.zh-CN.md)先预览，再应用核对后的快照。安装0.2.0不会自动迁移V1；V2运行时会拒绝未迁移的旧根。
3. 将新人格行的`memoryRoot`和空间配置指向目标目录，新建会话并选择**鲸鱼娘**。当前只注册`whale-soul`；历史会话若引用已移除预设，需在宿主中改选当前预设。
4. 核对一条迁移偏好和一段重要经历，重启后再次回忆。在评估新版期间保留原V1目录。

默认根为`~/.dsh/whale-soul/memory`；设置`DSH_HOME`后为`$DSH_HOME/whale-soul/memory`。Web与桌面未另行配置时共用此根，修改profile名称不能隔离记忆。

如需退回0.1.x，恢复原包及配置，并使用保全的V1根。新版V2产生的修改不会自动转换回V1。早期实验V2根走独立的[存储升级流程](self-integrity.zh-CN.md)。

## 安装与当前边界

- 要求DSH `0.2.1-rc.3`、Node.js `>=22.12.0`。
- Web本地包安装：`dsh plugin --profile web add /绝对路径/dsh-whale-soul-0.2.0.tgz`。桌面端从应用的 **Plugins** 安装，标准CLI不能管理其保留profile。
- 当前V2反思用于人格成长，不生成叙事梦日记；[V1梦日记](MEMORY-V1.zh-CN.md)是历史行为。
- 普通聊天中定点删除某个已存细节尚未实现，使用[本地管理流程](management.zh-CN.md)。
- 可选身体在陪伴应用晚启动时可能需要新会话或重新加载。长期人格表现与完整可选身体旅程仍单独验收。
