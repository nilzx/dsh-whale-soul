# 会话个体归属边界

鲸鱼娘通过宿主侧预约和记忆根镜像，把真实会话绑定到一个独立个体。权威文件只存标识符、结构元数据和哈希；普通记忆导出不能授予会话归属。

首次认领要求会话确实新建，并独立观察完整事件前缀。观察器挂在宿主根上，覆盖Web在绑定人格作用域前写入的权限初始化；只有真实Agent归属于本人格作用域时，才记录人格参与的首个实质事件。

官方的`permission/preset`、`sandbox/mode`、`approval/policy`属于配置元数据，要求字段和值符合约定；夹带正文、未知事件仍视为实质历史。这不会修改权限策略或授权操作。冷恢复和伪造空投影不能冒充新会话。

人格卸载时销毁其观察器。已确认会话仍受独立宿主分发注册表限制；换提示词或清除记忆不能让新个体接管旧会话。
